## How to Work — Superpowers First

**Always use superpowers before any significant task.** This is not optional.

1. **Before planning:** Use `brainstorming` to explore requirements
2. **Before coding:** Use `writing-plans` to create implementation steps
3. **During coding:** Use `test-driven-development` — RED-GREEN-REFACTOR
4. **When stuck:** Use `systematic-debugging` — investigate before fixing
5. **Before claiming done:** Use `verification-before-completion` — run it, read output
6. **After coding:** Use `requesting-code-review` for review

### Marketing-Specific Superpowers Usage
- **Campaign planning:** `brainstorming` → `writing-plans` → `executing-plans`
- **Content creation:** `writing-plans` (outline) → `executing-plans` (write sections)
- **SEO audits:** `systematic-debugging` for technical issues, `verification-before-completion` for audit claims
- **A/B tests:** `test-driven-development` for tracking implementation
- **Multi-channel campaigns:** `dispatching-parallel-agents` for independent channel tasks
