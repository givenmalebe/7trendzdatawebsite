# 7Trendz Data - AI & Data Science Consulting Website

A modern, full-stack web application for 7Trendz Data, a leading AI and data science consulting company. Built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Modern Design**: Clean, professional interface with responsive design
- **Full-Stack Architecture**: Built with Next.js App Router for optimal performance
- **Service Showcase**: Comprehensive pages for all AI and data science services
- **Project Portfolio**: Interactive case studies and success stories
- **Blog System**: Knowledge center with AI and tech insights
- **Contact System**: Professional contact forms and inquiry handling
- **Admin Dashboard**: Content management system for easy updates
- **SEO Optimized**: Built-in SEO best practices and meta optimization
- **Mobile Responsive**: Fully responsive design for all devices

## 🛠 Tech Stack

### Frontend
- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - Modern UI component library
- **Lucide React** - Beautiful icon library

### Backend
- **Next.js API Routes** - Serverless API endpoints
- **Server Actions** - Modern form handling
- **TypeScript** - Full-stack type safety

### Deployment
- **Vercel** - Optimized for Next.js deployment
- **Edge Functions** - Global performance optimization

## 🔧 Installation & Setup

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/your-username/7trendz-data-website.git
   cd 7trendz-data-website
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   \`\`\`

3. **Run the development server**
   \`\`\`bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   \`\`\`

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 🚀 Deployment

### Deploy to Vercel (Recommended)

1. **Push to GitHub**
   \`\`\`bash
   git add .
   git commit -m "Initial commit"
   git push origin main
   \`\`\`

2. **Deploy with Vercel**
   - Visit [vercel.com](https://vercel.com)
   - Import your GitHub repository
   - Configure environment variables (if any)
   - Deploy automatically

### Environment Variables

Create a \`.env.local\` file for local development:

\`\`\`env
# Add your environment variables here
NEXT_PUBLIC_SITE_URL=http://localhost:3000
\`\`\`
